# 隱私權

AudioForge 是一款在你的電腦上執行的音樂播放器。它沒有帳戶、沒有廣告、沒有分析統計，也不會追蹤你。

## App 會讀取什麼

你新增的音樂資料夾，以及你開啟的檔案。

## 什麼會留在你的電腦上

你的設定、播放清單和智慧播放清單、播放佇列、播放次數和喜愛的歌曲、資料庫快取、調性/BPM 分析結果、偵測到的類型、影片桌布和視覺效果設定以及警告記錄，儲存在 `%APPDATA%\AudioForge` 中；歌詞快取儲存在暫存檔案資料夾中。你的 Musixmatch API 金鑰由 Windows 加密，只有你的 Windows 帳戶可以讀取。

解除安裝 AudioForge 時會保留這個資料夾，因此重新安裝後資料庫和播放清單仍在。刪除該資料夾即可清除所有內容。

## 什麼會離開你的電腦（僅在需要時）

**LRCLIB**（lrclib.net）：用於查詢歌詞，傳送歌曲的標題和演出者。

**Musixmatch**：歌曲的標題和演出者，以及你的 API 金鑰。僅在你新增了金鑰時。

**MusicBrainz**（musicbrainz.org）：歌曲的標題和演出者，僅在你使用「編輯標籤 > MusicBrainz」或「從網路填入」時。

**GitHub**（api.github.com）：一次請求，取得 AudioForge 的版本清單，用來告訴你有沒有更新。僅在你按一下「設定」中的「版本」，或開啟「自動檢查更新」時（預設為關閉）。

**Discord**：如果你開啟了動態狀態，歌曲的標題、演出者和播放時間會傳送給你電腦上的 Discord App，並顯示在你的 Discord 個人檔案上。

類型偵測完全在你的電腦上進行，不會上傳任何內容。

這些服務會看到你電腦的 IP 位址，就像你造訪任何網站一樣。它們各自的隱私權政策適用。

## 回報問題

「回報問題」會在你的電子郵件 App 中開啟一封郵件，並預先填好 App 版本、Windows 版本和語言。在你親自寄出之前，不會傳送任何內容。

## 你的檔案

只有在你儲存時，本 App 才會變更歌曲的標籤或封面；只有在你確認後，才會將檔案移到資源回收筒。
