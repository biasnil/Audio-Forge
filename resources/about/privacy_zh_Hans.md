# 隐私

AudioForge 是一款在你的电脑上运行的音乐播放器。它没有账户、没有广告、没有分析统计，也不进行跟踪。

## 应用会读取什么

你添加的音乐文件夹，以及你打开的文件。

## 什么会留在你的电脑上

你的设置、播放列表和智能播放列表、播放队列、播放次数和喜欢的歌曲、资料库缓存、调性/BPM 分析结果、检测到的流派、视频壁纸和可视化效果设置以及警告日志，保存在 `%APPDATA%\AudioForge` 中；歌词缓存保存在临时文件夹中。你的 Musixmatch API 密钥由 Windows 加密，只有你的 Windows 账户可以读取。

卸载 AudioForge 时会保留这个文件夹，因此重新安装后资料库和播放列表仍在。删除该文件夹即可清除所有内容。

## 什么会离开你的电脑（仅在需要时）

**LRCLIB**（lrclib.net）：用于查找歌词，发送歌曲的标题和艺人。

**Musixmatch**：歌曲的标题和艺人，以及你的 API 密钥。仅在你添加了密钥时。

**MusicBrainz**（musicbrainz.org）：歌曲的标题和艺人，仅在你使用“编辑标签 > MusicBrainz”或“从网络填写”时。

**GitHub**（api.github.com）：一次请求，获取 AudioForge 的版本列表，用于告诉你有没有更新。仅在你点击“设置”中的“版本”，或开启“自动检查更新”时（默认关闭）。

**Discord**：如果你开启了动态状态，歌曲的标题、艺人和播放时间会发送给你电脑上的 Discord 应用，并显示在你的 Discord 个人资料上。

流派检测完全在你的电脑上进行，不会上传任何内容。

这些服务会看到你电脑的 IP 地址，就像你访问任何网站一样。它们各自的隐私政策适用。

## 报告问题

“报告问题”会在你的邮件应用中打开一封邮件，并预先填好应用版本、Windows 版本和语言。在你亲自发送之前，不会发送任何内容。

## 你的文件

只有在你保存时，本应用才会更改歌曲的标签或封面；只有在你确认后，才会将文件移到回收站。
