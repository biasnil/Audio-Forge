# Confidentialité

AudioForge est un lecteur de musique qui fonctionne sur votre ordinateur. Il n'a ni compte, ni publicité, ni statistiques d'usage, ni pistage.

## Ce que l'application lit

Les dossiers de musique que vous ajoutez, et les fichiers que vous ouvrez.

## Ce qui reste sur votre ordinateur

Vos paramètres, listes de lecture et listes intelligentes, file d'attente, nombres d'écoutes et coups de cœur, cache de la bibliothèque, analyse de tonalité/BPM, genres détectés, choix de fonds d'écran vidéo et du visualiseur et journal des avertissements, dans `%APPDATA%\AudioForge`, ainsi que le cache des paroles dans votre dossier de fichiers temporaires. Votre clé API Musixmatch est chiffrée par Windows : seul votre compte Windows peut la lire.

La désinstallation d'AudioForge conserve ce dossier, pour qu'une réinstallation garde votre bibliothèque et vos listes de lecture. Supprimez le dossier pour tout effacer.

## Ce qui quitte votre ordinateur, et seulement si nécessaire

**LRCLIB** (lrclib.net) : pour trouver les paroles, le titre et l'artiste du morceau.

**Musixmatch** : le titre et l'artiste du morceau, et votre clé API. Seulement si vous avez ajouté une clé.

**MusicBrainz** (musicbrainz.org) : le titre et l'artiste du morceau, quand vous utilisez Baliser > MusicBrainz ou Remplir depuis Internet.

**GitHub** (api.github.com) : une requête pour la liste des versions d'AudioForge, afin de vous signaler les mises à jour. Seulement quand vous cliquez sur Version dans les Paramètres, ou si vous activez Rechercher les mises à jour automatiquement (désactivé tant que vous ne l'activez pas).

**Discord** : si vous activez Rich Presence, le titre, l'artiste et la durée de lecture du morceau sont transmis à l'application Discord de votre ordinateur, qui les affiche sur votre profil Discord.

La détection des genres se fait entièrement sur votre ordinateur. Rien n'est envoyé en ligne.

Ces services voient l'adresse IP de votre ordinateur, comme tout site web que vous visitez. Leurs propres politiques de confidentialité s'appliquent.

## Signaler un problème

Signaler un problème ouvre un e-mail dans votre application de messagerie, avec la version de l'application, la version de Windows et la langue déjà remplies. Rien n'est envoyé tant que vous ne l'envoyez pas vous-même.

## Vos fichiers

L'application ne modifie les balises ou la pochette d'un morceau que lorsque vous enregistrez, et ne place un fichier dans la Corbeille qu'après votre confirmation.
