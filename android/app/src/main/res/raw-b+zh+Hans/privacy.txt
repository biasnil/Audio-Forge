# 隐私

AudioForge 是在你手机上运行的音乐播放器。它没有账户、没有广告、没有统计分析，也不会追踪你。

# 应用会读取什么

你允许访问时手机上的音乐库，以及你自己添加的文件夹。

# 保留在手机上的内容

你的设置、播放列表、播放次数和喜欢的歌曲、歌词缓存、你的播客订阅、你的收听记录（用于收听统计）、调性和 BPM 分析结果、流派检测结果，以及你的 Musixmatch API 密钥（使用 Android Keystore 加密）。

卸载应用或清除其存储空间会删除以上所有内容。如果手机开启了 Android 备份，Android 可能会像对待大多数应用一样，把本应用的设置和播放列表包含在手机备份中，保存到你的 Google 账户。Musixmatch 密钥无法从备份恢复，需要重新输入。

# 仅在需要时离开手机的内容

LRCLIB（lrclib.net）：为了查找歌词，发送歌曲的标题和艺人，或根据文件名生成的搜索词。

Musixmatch：歌曲的标题和艺人，以及你的 API 密钥。仅在你添加了密钥时发送。

GitHub（api.github.com）：一次请求，用于获取 AudioForge 最新版本的版本号，以便提醒你更新。你可以在“设置”的“关于”中关闭此功能。

Apple（itunes.apple.com）：你搜索播客时输入的文字。搜索结果中的节目封面从 Apple 的服务器加载。

播客托管方：当你打开节目、检查新单集或下载单集时，会从该节目使用的服务器获取节目的订阅源、封面和音频。下载由 Android 的下载管理器完成，并保存到手机的 Podcasts 文件夹。

Radio Browser（radio-browser.info）：你在“电台”标签页中搜索的内容（电台名称、标签或国家/地区），以及你播放的电台（它会计数）。电台标志从各电台的网站加载。

电台：当你播放电台时，音频流来自该电台自己的服务器，服务器会看到你的 IP 地址。

与你访问任何网站一样，这些服务会看到你手机的 IP 地址。它们各自的隐私政策适用。

流派检测完全在你的手机上进行，不会上传任何内容。

# 你的文件

只有在你点按“保存”时，应用才会修改歌曲的标签或封面；只有在你确认后，应用才会删除歌曲。
