# Confidentialité

AudioForge est un lecteur de musique qui fonctionne sur votre téléphone. Il n'a ni compte, ni publicité, ni statistiques d'utilisation, ni suivi.

# Ce que l'application lit

La bibliothèque musicale de votre téléphone, si vous l'autorisez, et les dossiers que vous ajoutez vous-même.

# Ce qui reste sur votre téléphone

Vos réglages, playlists, nombres d'écoutes et coups de cœur, le cache des paroles, les résultats de l'analyse de tonalité et de BPM, et votre clé API Musixmatch, chiffrée avec le Keystore Android.

Désinstaller l'application ou effacer ses données supprime tout cela. Si la sauvegarde Android est activée sur votre téléphone, Android peut inclure les réglages et les playlists de l'application dans la sauvegarde de votre téléphone sur votre compte Google, comme pour la plupart des applications. La clé Musixmatch ne peut pas être restaurée depuis une sauvegarde et doit être saisie à nouveau.

# Ce qui quitte votre téléphone, et seulement si nécessaire

LRCLIB (lrclib.net) : pour trouver les paroles, le titre et l'artiste du morceau, ou une recherche construite à partir du nom du fichier.

Musixmatch : le titre et l'artiste du morceau, ainsi que votre clé API. Seulement si vous avez ajouté une clé.

GitHub (api.github.com) : une requête pour connaître le numéro de la dernière version d'AudioForge, afin de vous signaler les mises à jour. Vous pouvez désactiver cela dans Réglages, sous À propos.

Ces services voient l'adresse IP de votre téléphone, comme tout site web que vous visitez. Leurs propres politiques de confidentialité s'appliquent.

# Vos fichiers

L'application ne modifie les balises ou la pochette d'un morceau que lorsque vous appuyez sur Enregistrer, et ne supprime un morceau qu'après votre confirmation.
