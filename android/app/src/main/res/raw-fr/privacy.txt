# Confidentialité

AudioForge est un lecteur de musique qui fonctionne sur votre téléphone. Il n'a ni compte, ni publicité, ni statistiques d'utilisation, ni suivi.

# Ce que l'application lit

La bibliothèque musicale de votre téléphone, si vous l'autorisez, et les dossiers que vous ajoutez vous-même.

# Ce qui reste sur votre téléphone

Vos réglages, playlists, nombres d'écoutes et coups de cœur, le cache des paroles, vos abonnements aux podcasts, votre historique d'écoute (pour les Statistiques d'écoute), les résultats de l'analyse de tonalité et de BPM et de la détection des genres, et votre clé API Musixmatch, chiffrée avec le Keystore Android. Ainsi que vos signets et votre progression dans les livres audio, et les pochettes d'albums trouvées en ligne.

Désinstaller l'application ou effacer ses données supprime tout cela. Si la sauvegarde Android est activée sur votre téléphone, Android peut inclure les réglages et les playlists de l'application dans la sauvegarde de votre téléphone sur votre compte Google, comme pour la plupart des applications. La clé Musixmatch ne peut pas être restaurée depuis une sauvegarde et doit être saisie à nouveau.

# Ce qui quitte votre téléphone, et seulement si nécessaire

LRCLIB (lrclib.net) : pour trouver les paroles, le titre et l'artiste du morceau, ou une recherche construite à partir du nom du fichier.

Musixmatch : le titre et l'artiste du morceau, ainsi que votre clé API. Seulement si vous avez ajouté une clé.

GitHub (api.github.com) : une requête pour connaître le numéro de la dernière version d'AudioForge, afin de vous signaler les mises à jour. Vous pouvez désactiver cela dans Réglages, sous À propos.

Apple (itunes.apple.com) : les mots que vous saisissez quand vous recherchez des podcasts. Les pochettes des émissions dans les résultats sont chargées depuis les serveurs d'Apple.

Apple (itunes.apple.com), pour les tags et pochettes manquants : quand vous touchez Trouver les infos manquantes dans l'éditeur de tags, le titre et l'artiste du morceau ; quand vous utilisez Trouver les pochettes manquantes dans les Réglages, le nom et l'artiste de chaque album, ou pour un morceau sans album, son titre et son artiste. Les pochettes sont téléchargées depuis les serveurs d'Apple.

Deezer (api.deezer.com) : les mêmes informations sur le morceau ou l'album, seulement quand Apple ne trouve rien. Les pochettes sont téléchargées depuis les serveurs de Deezer.

Internet Archive (archive.org), pour les livres audio gratuits : les mots que vous tapez quand vous utilisez Trouver des livres audio gratuits dans l'onglet Livres audio, et le livre que vous ouvrez ou téléchargez. Les pochettes et les fichiers audio des livres sont téléchargés depuis archive.org ; les téléchargements sont faits par le gestionnaire de téléchargements d'Android et enregistrés dans le dossier Audiobooks de votre téléphone.

Hébergeurs de podcasts : quand vous ouvrez une émission, recherchez de nouveaux épisodes ou téléchargez un épisode, le flux, la pochette et l'audio de l'émission sont récupérés sur les serveurs qu'elle utilise. Les téléchargements sont faits par le gestionnaire de téléchargement d'Android et enregistrés dans le dossier Podcasts de votre téléphone.

Radio Browser (radio-browser.info) : ce que vous recherchez dans l'onglet Radio (nom de station, étiquette ou pays), et la station que vous écoutez, qu'il comptabilise. Les logos des stations sont chargés depuis leurs sites.

Stations de radio : quand vous écoutez une station, le flux vient du serveur de la station, qui voit votre adresse IP.

Ces services voient l'adresse IP de votre téléphone, comme tout site web que vous visitez. Leurs propres politiques de confidentialité s'appliquent.

La détection des genres se fait entièrement sur votre téléphone. Rien n'est envoyé.

# Vos fichiers

L'application ne modifie les balises ou la pochette d'un morceau que lorsque vous appuyez sur Enregistrer, et ne supprime un morceau qu'après votre confirmation.
