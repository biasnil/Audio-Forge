# 隱私權

AudioForge 是在你手機上執行的音樂播放器。它沒有帳戶、沒有廣告、沒有數據分析，也不會追蹤你。

# App 會讀取的內容

你允許存取時手機上的音樂庫，以及你自己新增的資料夾。

# 保留在手機上的內容

你的設定、播放清單、播放次數和喜愛的歌曲、歌詞快取、調性和 BPM 分析結果，以及你的 Musixmatch API 金鑰（使用 Android Keystore 加密）。

解除安裝 App 或清除其儲存空間會刪除以上所有內容。如果手機開啟了 Android 備份，Android 可能會像對待大多數 App 一樣，將本 App 的設定和播放清單納入手機備份，儲存到你的 Google 帳戶。Musixmatch 金鑰無法從備份還原，需要重新輸入。

# 僅在需要時離開手機的內容

LRCLIB（lrclib.net）：為了尋找歌詞，傳送歌曲的標題和演出者，或根據檔案名稱產生的搜尋字詞。

Musixmatch：歌曲的標題和演出者，以及你的 API 金鑰。只有在你加入金鑰時才會傳送。

GitHub（api.github.com）：一次請求，用來取得 AudioForge 最新版本的版本號碼，以便通知你更新。你可以在「設定」的「關於」中關閉此功能。

和你瀏覽任何網站一樣，這些服務會看到你手機的 IP 位址。它們各自的隱私權政策適用。

# 你的檔案

只有在你輕觸「儲存」時，App 才會修改歌曲的標籤或封面；只有在你確認後，App 才會刪除歌曲。
