# 隱私權

AudioForge 是在你手機上執行的音樂播放器。它沒有帳戶、沒有廣告、沒有數據分析，也不會追蹤你。

# App 會讀取的內容

你允許存取時手機上的音樂庫，以及你自己新增的資料夾。

# 保留在手機上的內容

你的設定、播放清單、播放次數和喜愛的歌曲、歌詞快取、你的 Podcast 訂閱、你的收聽紀錄（用於收聽統計）、調性和 BPM 分析結果、類型偵測結果，以及你的 Musixmatch API 金鑰（使用 Android Keystore 加密）。此外還有你的有聲書書籤和進度，以及線上找到的專輯封面。

解除安裝 App 或清除其儲存空間會刪除以上所有內容。如果手機開啟了 Android 備份，Android 可能會像對待大多數 App 一樣，將本 App 的設定和播放清單納入手機備份，儲存到你的 Google 帳戶。Musixmatch 金鑰無法從備份還原，需要重新輸入。

# 僅在需要時離開手機的內容

LRCLIB（lrclib.net）：為了尋找歌詞，傳送歌曲的標題和演出者，或根據檔案名稱產生的搜尋字詞。

Musixmatch：歌曲的標題和演出者，以及你的 API 金鑰。只有在你加入金鑰時才會傳送。

GitHub（api.github.com）：一次請求，用來取得 AudioForge 最新版本的版本號碼，以便通知你更新。你可以在「設定」的「關於」中關閉此功能。

Apple（itunes.apple.com）：你搜尋 Podcast 時輸入的文字。搜尋結果中的節目封面從 Apple 的伺服器載入。

Apple（itunes.apple.com），用於補齊缺少的標籤和封面：在標籤編輯器中點按「尋找缺少的資訊」時，傳送歌曲的標題和演出者；在設定中使用「尋找缺少的封面」時，傳送每張專輯的名稱和演出者。封面從 Apple 的伺服器下載。

Deezer（api.deezer.com）：同樣的歌曲或專輯資訊，只有在 Apple 找不到相符結果時才會傳送。封面從 Deezer 的伺服器下載。

Podcast 託管方：當你開啟節目、檢查新單集或下載單集時，會從該節目使用的伺服器取得節目的訂閱來源、封面和音訊。下載由 Android 的下載管理員完成，並儲存到手機的 Podcasts 資料夾。

Radio Browser（radio-browser.info）：你在「電台」分頁中搜尋的內容（電台名稱、標籤或國家/地區），以及你播放的電台（它會計數）。電台標誌從各電台的網站載入。

電台：當你播放電台時，音訊串流來自該電台自己的伺服器，伺服器會看到你的 IP 位址。

和你瀏覽任何網站一樣，這些服務會看到你手機的 IP 位址。它們各自的隱私權政策適用。

類型偵測完全在你的手機上進行，不會上傳任何內容。

# 你的檔案

只有在你輕觸「儲存」時，App 才會修改歌曲的標籤或封面；只有在你確認後，App 才會刪除歌曲。
